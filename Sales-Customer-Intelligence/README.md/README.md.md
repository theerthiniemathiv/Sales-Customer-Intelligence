# Sales Performance & Customer Intelligence

## Project Overview
An end-to-end sales analytics project that analyzes transaction data, identifies customer purchasing patterns, segments customers using RFM analysis, and forecasts future sales revenue.

## Objectives
- Analyze overall sales performance.
- Identify top-performing products and customers.
- Understand customer purchasing behavior.
- Segment customers using Recency, Frequency, and Monetary (RFM) analysis.
- Forecast revenue for the next three months.

## Tools & Technologies
- Python – Data cleaning, analysis, RFM analysis and forecasting
- Pandas, NumPy, Matplotlib, Scikit-learn
- SQL – Business analysis and reporting
- Tableau Public – Interactive dashboards and visualizations
- Google Colab – Python development

## Dataset
- 8,808 original transaction records
- 8,617 records after exact duplicate removal
- 2,194 unique customers
- 5,547 unique invoices
- 273 unique products

The transaction records cover May 2024 to October 2025.

## Key Analysis
1. Data quality assessment and cleaning
2. Exploratory Data Analysis (EDA)
3. SQL-based business insights
4. Customer RFM segmentation
5. Sales revenue forecasting
6. Tableau dashboard development

## Key Findings
- Total revenue: IDR 909,042,082.10
- Average order value: approximately IDR 163,880
- Highest revenue product: BANNER OUTDOOR 280
- Largest customer segment: Regular Customers (1,311)
